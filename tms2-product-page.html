🧠 AI 성능 진단

SQL 텍스트와 실행계획을 분석하여 성능 병목 원인을 자동 진단. Full Table Scan, 비효율적 조인, 불필요한 서브쿼리 등을 즉시 식별합니다.

💡 AI 튜닝 가이드

문제 SQL에 대해 인덱스 생성, SQL 리팩토링, 힌트 추가 등 구체적인 튜닝 방안을 코드 레벨로 제시합니다.

🔄 SQL 리팩토링 어시스턴트

기존 SQL을 최적화된 형태로 자동 변환. 서브쿼리 → 조인, UNION → UNION ALL, 불필요한 정렬 제거 등을 제안합니다.

📊 성능 비교 분석
